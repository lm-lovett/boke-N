# boke-N

博客网站（前端 H5 + 后台管理端）最小可用版本。

## 已实现功能

### 后台管理端（RBAC）

- 管理员登录
- 菜单管理能力覆盖：
  - 角色管理
  - 用户管理
  - 资源管理
  - 文章管理
  - 违禁词管理
  - 评论记录管理
- 文章发布后可在前端展示
- 违禁词会在用户发表评论时生效拦截

### 前端 H5

- 文章列表 + 文章详情展示
- 用户注册/登录
- 仅登录用户可发表评论
- 左侧（侧边栏）展示浏览量 Top10 文章
- 当没有任何文章时，显示最近天气（默认上海市）

## 技术栈

- Node.js + Express
- 原生 HTML/CSS/JavaScript
- 本地 JSON 文件存储（`data/db.json`）

## 快速启动

```bash
npm install
npm start
```

启动后访问：

- 前端 H5：`http://localhost:3000/`
- 后台管理端：`http://localhost:3000/admin`

## 默认测试账号

- 管理员：`admin / Admin123!`
- 普通用户：`demo / Demo123!`

## 说明

- 当前天气接口使用演示数据，后续可替换为真实天气 API。
- 当前存储方式为本地 JSON，后续可平滑升级到 MySQL/PostgreSQL。
